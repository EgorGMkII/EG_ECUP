# Historical research scripts

Audits, diagnostics, notebook generators и submission recipes из scratch
сохранены здесь. Запуск из корня с PYTHONPATH=.; часть требует исторические
checkpoints/banks или запускает обучение. Не запускать весь каталог.

Используемый cloud probe — `scripts/research/test_datasphere_cloud.py`,
manifest — `configs/datasphere/archive/datasphere.test.yaml`.
Карта переносов — `docs/FILE_RELOCATIONS.md`. Данные и дорогостоящие результаты
не удалены. Старые builders могут снова создать scratch как mmap workspace.
